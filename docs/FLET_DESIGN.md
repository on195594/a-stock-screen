# 个人研究工作台：设计与实施边界

**目标：发现同业候选、看懂事实变化、继续个人研究。** 不做买入评分、交易、账户、回测、自动选股、通知或AI平台。

本文只维护有效合同、[下一阶段](#next-stage)和[验收底线](#acceptance)。使用命令见[README](../README.md)，代码入口见[导航](README.md)。历史设计、试验、逐次测试记录查Git；不再复制SQL、函数签名或另一份路线图。目标不等于已实现、已部署或本人验收。

## 1. 当前范围

- 单用户、Linux VPS、Flet动态Web，兼容手机浏览器；两个主入口：我的关注、同业发现。
- 已有：peer/watch独立任务、前三与参照事实、一键关注、五层变化分组、已阅对照、可选笔记/下一步、暂停恢复、分组只读字段卡、CLI备份/隔离恢复。
- 当前已阅按钮仍在可选笔记区；外部笔记链接只支持保存/编辑，没有打开入口。独立已阅、官方披露入口不是已上线功能。
- S3-R1代码侧已有加载/读取失败重试、peer/watch/重扫统一受理反馈、离页保留未确认请求编号、迟到读结果不改新页滚动位置；窄屏更新按钮不再被挤出，demo新会话按请求路由读取。生产深链接仍先登录，不继承demo身份。
- 未闭合：曾出现移动输入误点及间歇空白；最小复验发现语义节点滚动与焦点后回填不同步，测试等待实际几何/编辑值/选区而非盲目延时。该测试修正不证明真机问题已根治；本人OAuth、真实watch/原文核对、常用真机/断网提示、性能和异机恢复分别pending。
- `a-stock-tracker`只读，不改其代码、WATCHLIST、数据库、cron或历史实验，不恢复Framework A。不依赖相邻仓库、Token或生产数据才能运行demo/测试。

## 2. 最小架构

| 层 | 唯一职责/入口 |
|---|---|
| `screen.py` | 原peer-screen-v1算法、离线CLI与显式刷新；不是投资决策模型 |
| `workspace.py` | 三表、导入、快照身份/版本/已阅校验；DDL与schema版本以初始化/验证代码为准 |
| `services.py` | 鉴权后的查询和个人写操作；主页/详情共用事实比较合同 |
| `app.py` / `auth.py` | 普通页面构建＋异步回调、临时会话、OAuth/ASGI边界 |
| `worker.py` / `watch.py` | 独立进程按冻结意图采集、核验、发布；不依赖页面在线 |
| `maintenance.py` / `manage.py` | 显式初始化、导入、只读源备份、新目录恢复 |

一个Web进程、一个串行worker、一个SQLite工作区；Compose共用镜像但分配角色凭据，Nginx代理HTTPS/WSS。不增加后台队列平台、响应式框架、行情库或证据库。以锁定Flet 1.0 API为准；事件循环不做同步网络、长计算或sleep，更新不能放进page.run_task。MCP只用于本地开发，不是产品运行依赖或公网服务。

## 3. 事实与展示合同

- peer-screen-v1的资格、范围、平均并列名次、前三及历史结果不变。PB较低/ROE较高只安排核查顺序，不等于低估、无风险或买入建议。
- 发现页显示前三＋参照、实际PB、三年逐年加权ROE及均值、日期、粗行业、最多50家/偏向大市值的限制；参照不合格也说明原因。个人暂停不改变算法名次，不拿第四名替第三名。
- PB中位数仅比较同一完整、已验证、同规则快照中同估值日/同年度的合格样本，含本公司且至少2家；partial、重复、未知规则或口径不同不比较。ROE趋势按年度，最新年度为负单独提醒。
- 事实、个人判断、未核查事项分开。风险/上市状态未知不等于风险解除；现金流、杠杆、资产质量、一次性损益与审计意见不得由PB/ROE推断已核验。
- 首页五层：数据异常与缺口→公司状态变化→指标与资料变化→仅数据日更新→暂无未阅变化；同层研究中优先，暂停默认收起且不计待阅数，仍计关注总数。已有下一步显示摘要，空笔记不催填。
- 详情先给当前值和真实变化，完整字段/来源按需展开；首次待阅无空旧值箭头。元数据双方未记录可收起，核心缺口及有值变缺失不得隐藏；“未记录”不等于接口不提供。
- 最新尝试与当前完整榜分开。partial/失败/零候选/损坏都有原因与可行动出口，旧榜注明旧日期；不同公司数据日不统一冒称“最新”。未知/replay不冒充新观察。
- 固定watch只更新冻结公司事实，不重筛/重排名；非正PB/ROE、ST、退市或掉出前50不阻止获取可得事实。最近peer名次保留旧参照/日期，不冒充watch新名次。
- 路由保留来源页、参照、指定任务/run与滚动上下文；历史任务不跳成另一参照或最新榜。重新扫描必须确认后提交；取消不提交，获取成功不保证日期/数值变化。

## 4. 私人记录与已阅

只保留`screen_runs`、`watch_items`、`update_jobs`三张业务表；事实存不可变JSON，个人状态存SQLite。Page/Session/浏览器存储不是永久笔记库。

- 关注幂等，无需笔记，不覆盖旧内容、不推进ack；服务首次加入使用expected_revision=0，数据库初始revision=1。
- reason、next_check、note_url可空；保存检查revision，删除/状态切换还核对原updated_at，防止删除重加后的旧页覆盖。暂停只改个人状态，恢复明确为observe；笔记、来源run、ack保留。
- 直接比较实际ack_run_id→displayed_run_id，不用中间run替基准。比较PB/日期、年度ROE/公告/修订、风险/上市状态、来源/规则/范围/完整性；新增或退出年度缺项不补零。仅核查时间变化不算财务变化。
- 只有明确“变化已阅”推进实际显示且可用的run；提交时重验授权、版本、两份快照及日期防倒退。基准损坏/歧义、未知规则、最新缺口不能自动换基准或确认旧事实为新资料。打开详情、关注、保存笔记、更新均不推进ack。
- 未保存离开提供保存/放弃/继续编辑。断线保留当前会话草稿及原版本，冲突不可直接保存；强制刷新/浏览器回收可能丢草稿，不得显示已保存。切页/退出后的异步结果和旧控件回调不得重显或覆盖私人内容。
- 删除研究记录要确认，不删共享快照、外部笔记原文或备份。清理失败/中断任务只隐藏列表，保留请求防重放；不消除事实缺口，不允许清理在途/成功任务。
- URL保存时校验https、无嵌入凭据和长度；未来打开前再次校验授权/URL，只由本人点击后浏览器打开，不让服务端抓取任意链接。

## 5. 更新与持久化

- 只有用户提交的任务才能请求行情；打开页面、保存、已阅不联网。OAuth与行情网络分开。CLI保留`--input`离线和`--refresh`显式联网。
- request先查ID/别名与意图，再读取允许参照或1—50家未暂停关注、日历并冻结范围/日期/intent_hash。同ID不同意图拒绝，同范围在途去重，队列上限3；排队后清单/日期变化不改原任务，回执不确定重试复用原ID。
- 默认目标日为小于上海“今天”的最近已证明交易日。验证SSE日历来源与范围，以min(covered_to, as_of)作为证明边界；仅缺周末可放行，缺任何工作日仍拒绝，不猜节假日或逐日回退。行情必须返回目标日，任务跨日不改日。
- 每次显式peer/watch重新核查财务，不承诺7日缓存复用。核查时间不同于公告日、报告期末、首次取得时间；旧缓存不能冒充本次成功核查。三年连续年度、代码、日期、来源/版本冲突、重复/截断及有限数值均校验。
- worker持进程锁；网络在事务外，提供真实阶段，不虚构逐公司进度或完成时间。任务失效/中断可恢复，不能依靠页面在线或重连重放。
- 快照在工作区内用固定job路径发布：临时文件/flush/fsync→不可覆盖最终文件→核验job/intent/日期/范围/哈希→登记。崩溃恢复重复执行仍幂等；partial不替换完整榜，损坏/未知来源降级或拒绝。
- SQLite参数绑定、显式短事务，schema/mode锁定且初始化原子幂等；生产WAL运行库须满足已修复版本检查，新demo可显式DELETE。tracker仅SQLite mode=ro，不调用其有副作用的get_db/CLI。
- 快照路径限制在工作区、读时核验哈希，原始导入去重；不改旧JSON，不从多个run拼出一份新完整资料。一次请求内可缓存，下次请求必须重新核验。

## 6. 认证、部署与恢复

- 生产GitHub OAuth同标签回跳，保留官方state校验和服务端数字ID白名单；actor可撤销/到期。私人读写/提交/异步呈现前鉴权，匿名仅见登录；退出、错误ID、过期后不能留私人视图。
- ASGI透传lifespan，校验Host/WS Origin、关闭/upload；不信任未授权转发头。demo只允许loopback Host/Origin、合成数据，不读取生产Token。生产配置缺失拒绝启动，不降为demo。
- web只需认证配置，worker只需行情配置；不互相要求secret。凭据、授权码、私人笔记不进日志/Git/assets/浏览器存储；工作区/快照/备份不是静态文件。具体变量与部署步骤见README、示例配置和Compose。
- 备份只读源库，经SQLite backup获取一致副本，从**副本库**枚举引用快照；新私有目录、schema/mode/路径/符号链接/哈希/完整性/外键均检查，不覆盖源或已有目录。
- 恢复验证清单，禁网写入全新目录，queued/running转interrupted，不启动服务或旧任务。任何失败副本都不认可；正式替换生产、传输/删除备份或定时维护另获授权。
- 当前目录fsync异常会被忽略，内容一致性不证明断电持久性；需验证父目录、完成标记顺序及失败处理。本机隔离恢复不等于VPS外灾备。保留最近7份/异机加密仍是待确认运维目标，不是已实现自动策略。

## 7. 验证原则

每个代码切片运行`make check`与`make test-mobile`，保留原算法/安全反例。测试用独立临时库与明确合成数据，默认禁真实接口、放行本地HTTP/WS；依赖先安装，缺浏览器非零退出，不清理demo/生产数据。

`uv run python test_mobile.py --reliability`在隔离合成工作区按360/390/430px各重复10次输入/保存/WebSocket重连/返回，首个失败即非零退出并留独立截图。语义点击等待可见几何、聚焦后原值和选区，不注入应用值；循环耗时包含驱动等待，不是保存响应或真机性能。

优先可读的合法基线＋单点反例，不复制大段fixture，不以删除断言或重跑直到绿替代修复。浏览器真实点击/输入/保存，不把Flet原生测试、canvas、截图或skip当动态Web验收。真机/真实数据未测就标pending，记录首次失败与剩余风险，不用测试数量宣称产品完成。

## 8. 当前任务与停止点

<a id="next-stage"></a>

### 下一阶段：一次只做一个获准切片

S1=看懂扫描，S2=持续研究，S3=真实使用验收。已有功能不再列成待建模块；先可靠，再缩短路径，再接来源，最后收口维护。

| 顺序 | 差量任务 | 退出条件 |
|---|---|---|
| **S3-R1 可靠性** | 最小复现导航/输入/重连；明确加载、断开、未提交/已受理/回执不确定、日历阻断与下一步；不自动刷新丢草稿 | 关键小流程360/390/430px各连续10次无未解释失败；完整E2E保留；本人至少两次会话含锁屏/切网络，无丢已保存内容或重复任务 |
| **S2-R1 最短研究路径** | 实际对照后独立明确已阅；已有下一步优先、任务日志次要；账户页说明资料/任务/阻断，路径折叠 | 已关注可确认公司从首页到详情再已阅至多2次点击，无需笔记；本人5次重开能回答看谁、变了什么、下一步；不弱化ack/冲突校验 |
| **S2-R2 来源核查** | 打开安全的已有note_url；区分接口来源、官方披露检索、个人笔记；用现有next_check手工交接外部研究 | 两家公司完成事实→官方检索/真实原文→下一步→重开续接；不猜PDF/页码，不把入口当已核验，不自动调用Agent、抓取报告或跨库写入 |
| **S3-R2 恢复收口** | 备份发布/同步失败注入；授权后取回VPS外加密副本并隔离恢复；本人完整使用验收 | 内容/引用一致、失败不冒充成功、旧任务不执行；记录恢复时间/数据损失窗口；正式替换另授权 |

R1真实数据需另获授权：1个适用参照、1—3家公司，核对目标日/身份/PB来源/三年加权ROE报告期和公告口径，再与发行人原文核对；内部算术检查与原文正确分开，不反复联网凑成功。故障只在隔离环境制造。本人OAuth、深链接、返回、中文编辑与网络切换不能由合成测试替代。

性能先记录设备/网络/缓存、冷/热启动、切页、保存和受理的样本数/中位数/最大值，再确认可接受目标；少量样本不报p95，行情总耗时不混成按钮响应。常用触控目标以44px为项目目标，文字/焦点/键盘及非颜色提示可用，危险操作与日常操作分离。

缺本人/数据/运维授权则交付隔离证据并标pending，不自动进入后续切片。保留Flet；仅在复现、局部修复后仍不满足本人目标时另议展示层，不并行两套前端。没有实际长列表问题不做搜索后台，没有已证明瓶颈不接新指标或AI。

### 验收底线

| 用户任务 | 必须证明 |
|---|---|
| U01 | 空工作区无需README/CLI即可扫描并一键关注 |
| U02 | 前三/参照、指标/年度/范围可比较，能解释继续核查理由而非复述名次 |
| U03 | partial/失败/零结果与旧榜分开，指定任务/返回/刷新不丢上下文、不重提 |
| U04 | 已有理由/下一步可续接；watch不依赖原池/前50、不重排名 |
| U05 | 已阅→当前对照先于确认，暂停/恢复、缺口、同值重查不误报 |
| U06 | 本人真机登录→研究→保存→锁屏/切网络→查原任务，失败可恢复、不重放 |
| U07 | 已阅不依赖笔记；原文/外部笔记可达，返回可继续下一步 |
| U08 | 授权取回异机备份并隔离恢复，记录/引用一致，旧任务不执行 |

| 安全/数据反例 | 必须保持 |
|---|---|
| A01 未登录/错误ID/过期/深链接 | 鉴权、state、Host/Origin与退出后私人视图清除 |
| A02 保存/刷新/两标签/删除重加 | 幂等加入、版本冲突拒绝、草稿不当作已保存 |
| A03 排名/并列/排除/旧规则 | 算法不变，unknown/replay/fixture不冒充生产新事实 |
| A04 日历/周末/跨UTC日 | 证明范围、仅周末例外、上海日期与冻结target_date |
| A05 旧财务/重复/错码/缺失 | 无证明不复用为最新，失败不推进核查时间，不冒充业务事实 |
| A06 双击/重发/两标签 | 先查ID/intent、别名/在途去重、清单变化不改任务 |
| A07 离页/双worker/终止 | 独立执行、进程锁、有限停止、重连不重提 |
| A08 文件/DB发布中断 | 不覆盖固定文件，错身份/日期/范围/哈希拒绝，恢复幂等 |
| A09 无tracker/Token的demo | 独立运行、模式隔离、角色配置分开、默认禁外部数据网 |
| A10 掉出前50/partial | watch保留，旧完整榜不被partial替换 |
| A11 多次更新只读其中一次 | 只确认实际显示且可用run，不倒退，缺失/未知不推进 |
| A12 真机/恢复/secret | 键盘/返回/草稿可用，备份引用一致，旧任务不执行，无凭据泄露 |

本人能独立完成发现→关注→更新→核查→下一步→已阅，资料日期/受理可解释、私人记录可恢复即停止扩建。提交、推送、部署、迁移、备份传输/删除均需具体授权；完成后只报实际行为、文件、测试、未验证项和启动方式。
